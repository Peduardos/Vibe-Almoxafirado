# Sistema de Almoxarifado - Mistral Vibe

Sistema web de controle de almoxarifado desenvolvido com auxílio do **Mistral Vibe**, utilizando **HTML**, **CSS** e **JavaScript**.

Este projeto integra um **Trabalho de Conclusão de Curso (TCC)** do curso de **Tecnologia em Sistemas para internet do IFSertãoPE - Campus Salgueiro**.

O objetivo é avaliar a **usabilidade da interface** com base nas dez **heurísticas de Nielsen**, e a **qualidade do código gerado**, segundo critérios de boa programação.

O sistema faz parte de um estudo comparativo envolvendo nove assistentes de IA gratuitos.

**Finalidade:** Exclusivamente acadêmica.
